# Журнал изменений

## 0.2.2

- `install.py` автоматически заменяет `127.0.0.1` на шлюз WSL2, если агент
  ставится внутри WSL и loopback relay недоступен.
- Документация по WSL и выбору адреса relay.

## 0.2.1

- Уведомления Telegram не блокируют цикл команд и WebSocket агента.
- Статус заявки отображается отдельно: ожидание, отказ, повторная заявка.
- `RSB_TELEGRAM_PROXY=auto`: автоматический подбор публичного прокси для Bot API.
- Тесты изолированы от локального `.env`.

## 0.2.0

- Онбординг нового пользователя: описание продукта, заявка на доступ,
  одобрение администратором через бота или CLI.
- Административные команды `rsb operator list/approve/deny`.
- `RSB_INSTALL_URL` и `RSB_INSTALL_SOURCE_URL`: бот выдаёт готовые команды
  установки для Windows и Linux/macOS.
- Standalone-режим `install.py`: скачивание исходников по URL, если скрипт
  запущен без репозитория.
- Миграция схемы БД до версии 2.
- Обновлены Docker-образ и релизный workflow.

## 0.1.0

Первая публичная версия.

- Relay на FastAPI с WebSocket-каналом для агентов.
- Telegram-бот с TOTP и allow-list операторов.
- Локальная панель хоста с паролем, запросами на подключение, журналом команд,
  снимками экрана и управлением правами.
- Явное согласие на каждое подключение и истечение запроса без ответа.
- Права `shell` и `screenshot`, выдаваемые хостом на сессию.
- Одноразовые учётные записи сессий и сохранение истории доступа.
- Установщик для Windows, Linux и macOS с автозапуском.
- SQLite-хранилище с аудитом и фоновой очисткой.
- Разделены liveness `/healthz` и readiness `/readyz`; проверка версии схемы.
- Ограничение частоты enrollment и аудит отказов.
- Сетевой слой: `rsb netcheck`, `rsb connect`, HTTP/HTTPS/SOCKS5-прокси,
  кэш и ротация, публичные списки прокси с GitHub.
- Опциональный WireGuard: локальные конфиги, источники и `--vpn`.
- Тесты протокола, безопасности, хранилища, сервиса, исполнителя команд,
  локальной панели, прокси и сквозной сценарий подключения.
