# Журнал изменений

## 0.1.0

Первая публичная версия.

- Relay на FastAPI с WebSocket-каналом для агентов.
- Telegram-бот с TOTP и allow-list операторов.
- Локальная панель хоста с паролем, запросами на подключение, журналом команд,
  снимками экрана и управлением правами.
- Явное согласие на каждое подключение и истечение запроса без ответа.
- Права `shell` и `screenshot`, выдаваемые хостом на сессию.
- Одноразовые учётные записи сессий и сохранение истории доступа.
- Установщик для Windows, Linux и macOS с автозапуском.
- SQLite-хранилище с аудитом и фоновой очисткой.
- Тесты протокола, безопасности, хранилища, сервиса, исполнителя команд,
  локальной панели и сквозной сценарий подключения.
