# Участие в разработке

## Окружение

```
python -m venv .venv
. .venv/bin/activate
pip install -e ".[dev]"
```

Windows:

```
py -m venv .venv
.\.venv\Scripts\activate
pip install -e ".[dev]"
```

## Проверки

```
ruff check .
ruff format --check .
pytest
```

Все три команды обязательны перед pull request. CI выполняет их на Windows,
Linux и macOS для Python 3.11-3.13.

## Правила

- Изменения в протоколе сопровождаются обновлением `docs/PROTOCOL.md`.
- Изменения в модели доступа или хранении секретов сопровождаются обновлением
  `docs/SECURITY.md`.
- Новые возможности агента не должны работать без явного подтверждения хоста.
- Запрещены скрытые функции: перехват ввода, снимки без сессии, обход панели.
- Код без комментариев-заглушек и без эмодзи в интерфейсе.
- Публичные функции имеют краткое описание назначения.

## Сообщения об уязвимостях

Не открывайте публичный issue. Напишите мейнтейнеру репозитория напрямую
и приложите шаги воспроизведения без реальных секретов и данных пользователей.

## Лицензия

Отправляя изменение, вы соглашаетесь с условиями Apache-2.0.
