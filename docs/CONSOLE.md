# Консольный клиент

`rsb console` — интерактивный операторский интерфейс для терминала. Он работает
через локальный HTTP API relay и не заменяет подтверждение на стороне хоста:
каждая сессия по-прежнему требует одобрения владельца машины.

## Включение

На сервере в `.env`:

```
RSB_CONSOLE_TOKEN=<длинный случайный токен>
RSB_CONSOLE_OPERATOR_ID=100000000
RSB_CONSOLE_ALLOW_REMOTE=false
```

`RSB_CONSOLE_OPERATOR_ID` — Telegram ID оператора, от имени которого действует
консоль. Если `0`, берётся первый ID из `RSB_ADMIN_IDS`.

После изменения `.env` перезапустите relay. API без токена отключён.

## Запуск

```
rsb console
rsb console --url http://127.0.0.1:30000
RSB_CONSOLE_TOKEN=... rsb console
```

По умолчанию URL берётся из `RSB_PUBLIC_URL` (`ws://` заменяется на `http://`).
Токен читается из `RSB_CONSOLE_TOKEN`.

## Команды

| Команда | Действие |
|---|---|
| `devices`, `ls` | список машин и прав |
| `connect <номер|id>` | запросить доступ у хоста |
| `status` | текущая сессия и последние команды |
| `screen` | один снимок с ANSI-предпросмотром |
| `save [путь]` | сохранить снимок |
| `open` | открыть снимок во внешнем просмотрщике |
| `watch` | live-просмотр до Ctrl+C |
| `audit` | последние события |
| `close` | завершить сессию |
| `quit` | выход |
| любая строка | выполнить в shell при активной сессии |

## Live-просмотр

`watch` запрашивает кадр раз в секунду и выводит его half-block ANSI
в truecolor. Хост видит каждый снимок в локальной панели и может завершить
сессию. Право `screenshot` должно быть разрешено политикой устройства и
выдано при подтверждении сессии.

Для живого просмотра в терминале нужен truecolor. В Windows Terminal,
iTerm2 и большинстве Linux-терминалов он есть. Если цвета не отображаются,
используйте `save` или `open`.

## Безопасность

- Консольный токен эквивалентен административному доступу. Не публикуйте его.
- `RSB_CONSOLE_ALLOW_REMOTE=false` разрешает только локальные адреса сервера.
- Для удалённой консоли включайте `RSB_CONSOLE_ALLOW_REMOTE=true` только
  вместе с TLS reverse proxy.
- Токен и `.env` не должны попадать в git.
- Все команды и снимки фиксируются в аудите; сессии закрываются по TTL.

## Ошибки

| Ответ | Причина |
|---|---|
| 404 | `RSB_CONSOLE_TOKEN` не задан, API отключён |
| 401 | неверный консольный токен |
| 403 | клиент не локальный, а `ALLOW_REMOTE` выключен |
| 503 | не настроен оператор консоли |
| 429 | слишком много запросов или команд |
